# Library Management System

A full-stack Library Management System built for PLP Final Project.

**Live App:** https://library-management-system-xi-ashen.vercel.app
**GitHub:** https://github.com/abdulwahabuakim-spec/library-management-system

## Features
- User Registration & Login (JWT Auth)
- Dashboard with Books, Members, Borrow Records
- Add Books (Title, Author, ISBN, Category)
- Borrow & Return Books
- Members Page - Lists all registered users

## Tech Stack
- Frontend: React - Deployed on Vercel
- Backend: NestJS - Deployed on Render
- Database: PostgreSQL with Prisma ORM

## How to Run Locally
1. Clone repo: git clone https://github.com/abdulwahabuakim-spec/library-management-system
2. Backend: cd api && npm install && npm run start:dev
3. Frontend: cd web && npm install && npm run dev
